## Guarantees (checked, not assumed)

- **Identical:** every file is written byte for byte from its Git object at the recorded revision, never from a working
  tree. `MANIFEST.json` lists each file's original path, revision, Git blob id, SHA-256 and size.
- **Recoverable twice:** from this folder, and from Git history (`git show <revision>:<path>`).
- **Inactive:** outside `mobile/` and `backend/`, so it is not compiled (TypeScript), linted, tested (Vitest) or
  bundled (Metro's project root is `mobile/`, with no extra watch folders). No live file references it.
- **No Quran data duplicated:** the Quran text database, the page-61 Quran SVG and other large generated data are
  pinned by blob id below, not copied.

Verify at any time (exits non-zero on any difference):

```sh
node design-archive/verify-archive.mjs
```

## Restoring a design

Each `original-source/` mirrors the repository path, so a file goes back to the same path. Either:

```sh
# From the archive (example: the original navigation bar)
cp "design-archive/mushaf-navigation-v1/original-source/mobile/src/components/MushafControlPanel.tsx" mobile/src/components/
# Or from Git, for any file in MANIFEST.json
git checkout 529a7241d9d79717df9ead4ac85e814be00cb3b1 -- mobile/src/components/MushafControlPanel.tsx
```

Restoring a whole design means restoring its files together (each README lists them), then running
`npm run typecheck && npm test` in `mobile/`. Later changes to shared files (for example `messages.ts`) need merging,
not overwriting: take only the parts the design uses.
